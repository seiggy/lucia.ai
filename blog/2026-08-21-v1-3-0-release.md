**Lucia v1.3.0** adds a complete remote observability stack, CUDA voice deployment for Jetson Orin Nano, speech pipeline metrics, and accessible System, Light, and Dark dashboard themes.

<!-- truncate -->

## See the whole system

The new OpenTelemetry stack combines Collector, Grafana, Tempo, Prometheus, Loki, and Caddy. Four fail-open telemetry modes let deployments choose metrics only, sampled tracing, full profiling, or no export. Five provisioned dashboards cover Lucia service health, speech processing, Jetson hosts, PostgreSQL, and Redis.

## Voice and edge deployment

The Jetson ARM64 stack packages AgentHost, PostgreSQL, Redis, CUDA ONNX Runtime, pinned voice models, infrastructure exporters, health checks, immutable deployment, and rollback tooling. Wyoming now limits concurrency around STT inference rather than idle connections, drains sessions during shutdown, and reuses GTCRN buffers to cut warm-hop allocations from about 144 KB to 1.4 KB.

## Quality and reliability

Evaluation sweeps now use repeated runs, deterministic seeds, typed provider settings, and explicit unavailable-score handling. Agent reloads, UTC timestamps, Home Assistant authentication, API key validation, async deadlines, traces, Redis startup, and release automation were also hardened.

There are no breaking changes. See the [full GitHub release](https://github.com/seiggy/lucia-dotnet/releases/tag/v1.3.0).
