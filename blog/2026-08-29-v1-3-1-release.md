**Lucia v1.3.1** stops loading unused VAD and wake-word pipelines by default, adds reproducible speaker-verification benchmarks, and fixes a cancellation loop that could consume a full CPU core.

<!-- truncate -->

`VadPipeline` and `WakeWordPipeline` feature flags now control engine registration and model activation. The generic AgentHost configuration leaves both disabled until they are needed.

The new speaker benchmark compares embedding models against labeled enrollment and test clips, emits stable JSON and Markdown reports, and supports per-model thresholds. The same release fixes shared background-task cancellation so one SSE heartbeat timeout cannot poison future waiters; production validation reduced roughly 80,000 exceptions per second to zero.

There are no breaking changes. See the [full GitHub release](https://github.com/seiggy/lucia-dotnet/releases/tag/v1.3.1).
