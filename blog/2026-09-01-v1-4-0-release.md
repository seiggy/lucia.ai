**Lucia v1.4.0** adds an official Appliance OS Image for the NVIDIA Jetson Orin Nano Super 8GB Developer Kit. Flash a microSD card, finish setup from a phone, and boot a native Lucia system from NVMe.

<!-- truncate -->

## One image, one supported device

The image targets the 8GB P3767-0005 module with Jetson Linux 36.5.2 and an NVMe drive of 64 GB or larger. It installs AgentHost, the dashboard, Redis, SQLite, CUDA voice libraries, pinned speech models, and a restricted appliance manager as native systemd services. The installed device doesn't need Docker.

Setup runs on an open, client-isolated `Lucia-XXXXXX` Wi-Fi network. The first browser claims the session, chooses the target NVMe and home network, sets a hostname and recovery password, then approves the destructive write with a device-specific erase phrase.

Lucia shows the dashboard owner key before it powers off. Save the key, remove the installer card, power the Jetson back on, and open `https://<hostname>.local:8099`.

## Built for recovery

Two Jetson Linux root partitions provide A/B operating-system slots. Separate `LUCIA` and `LUCIA_DATA` partitions keep application releases apart from Redis data, SQLite databases, certificates, and configuration.

Version 1.4.0 can discover compatible application and OS releases but can't install them yet. Signed update installation and rollback are planned for v1.4.1.

Read the [Appliance OS installation guide](/docs/getting-started/appliance-os) or see the [v1.4.0 release](https://github.com/seiggy/lucia-dotnet/releases/tag/v1.4.0).
